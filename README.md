I. Введение
сервис сокращения ссылок с возможностью управления лимитом
переходов и времени жизни ссылки.

II. Применяемые технологии:

1. openjdk 21.0.8 2025-07-15
2. Фреймформ Jmix 2.7.0.
3. PostgreSQL 17.5

III. Подготовка базы данных
Инструкция для операционной системы Ubuntu.
Подготовьте базу данных и пользователя:

sudo su postgres
psql
create user url with password 'url';
create database url;
\c url
grant all on schema public to url;

IV. Запуск приложения
Из корневого каталога:
./gradlew bootRun
Приложение будет запущено на порту 8080.
В консоли об этом будет сообщение.

V. Тестирование

1. Функциональное тестирование можно выполнить, войдя
   под тестовым пользователем admin и паролем admin.

2. Автоматизированное тестирование:
   из корневого каталога запустить ./gradlew test

VI. Создание пользователей
Создать пользователей. Назначить каждому роли.

1. Ресурсные роли:

1) ui-minimal (без этой роли не сможет даже войти).
2) user (иначе не сможет пользоваться сервисом -
   не увидит пунктов меню).
3) flowui-filter (желательно - тогда сможет для себя
   настроить фильтры).

2. Ограничения уровня строк
   user-can-manage-only-their-short-links (сможет
   управлять своими записями).

VII. Краткое руководство пользователя

1. Войти под администратором и задать опции:

1) Количество символов в короткой ссылке
2) URL данного сервиса
3) Время жизни ссылки (мин.)

2. Сокращенные ссылки копировать из детального представления
   ссылки, нажав кнопку "Копировать короткий URL".
